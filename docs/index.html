Ender 3 S1 firmware

A custom Marlin build for a Creality Ender 3 S1 on a 256 KiB STM32F103: 232,344 of 233,472 bytes used, 1,128 bytes free, and every feature cost measured by compiling it on and off rather than estimated.

The configurator

What is in the repository

  • The compiled firmware and display assets, with manifests and MD5s.
  • The exact configuration that produced them, and every hand edit with file:line.
  • A pinned, reproducible build chain and make verify (checksums, ARM vector tables, configuration assertions, 162 documentation links, 14 live service checks).
  • A measurement harness that turned 66 features into byte costs, and a configurator that predicts, compiles, verifies and writes the card.
  • The screen-recovery kit, including the evidence trail from the brick.
